# JavaScript Calculator

A simple, responsive calculator web application developed using HTML, JavaScript, and Bootstrap 5. It allows users to perform basic arithmetic operations through an easy-to-use interface.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Input validation
- Division-by-zero handling
- Clear input and result fields
- Bootstrap-based responsive layout

## Technologies Used

- HTML5
- JavaScript
- Bootstrap 5

## How to Run

1. Download or clone this repository.
2. Open `calculator.html` in a web browser.
3. Enter two numbers.
4. Click the desired arithmetic operation.
5. Click **Cancel** to clear the fields.

No backend or installation is required. Bootstrap is loaded through a CDN, so an internet connection is needed for its styling.
